## 1. ¿Qué es el Modelo Físico? 🗄

El **Modelo Físico de Datos**  representa la estructura final que tendrá la base de datos en un sistema gestor (DBMS) específico.

A diferencia del Modelo Lógico (MLD), el Modelo Físico (MFD) traduce las entidades y relaciones en **instrucciones SQL** que permiten crear las tablas y estructuras reales.

 El **MFD** Incluye:
- Especificación de tablas, columnas y tipos de datos.
- Definición de claves primarias y foráneas.
- Restricciones de integridad.
- Índices para optimizar consultas.
- Configuraciones específicas del DBMS.
